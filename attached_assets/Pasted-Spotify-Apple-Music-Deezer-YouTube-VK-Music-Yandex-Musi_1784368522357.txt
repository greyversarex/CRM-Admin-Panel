Как реализовать VK и Яндекс
Поскольку официального API практически нет, есть два варианта:
Вариант 1 (рекомендую)
Пользователь вставляет ссылку вручную:
VK Artist URL
Yandex Artist URL
Например:
https://music.yandex.ru/artist/1234567
https://vk.com/artist/9876543



После ввода имени артиста
Например:
Zafar Ayubi
Система автоматически ищет:
Spotify API
Apple Music API
Deezer API
YouTube API
и показывает:
☑️ Zafar Ayubi
Spotify ID: xxxxx
Followers: 1,044
Open Profile

☑️ Zafar Ayubi
Apple Artist ID: xxxxx
Open Profile

☑️ Zafar Ayubi
Deezer Artist ID: xxxxx
Fans: 5,234
