ЗАДАЧА 5: PUBLISHING — ДВА РЕЖИМА
БИЗНЕС-ТРЕБОВАНИЕ:
Заказчик подтвердил что publishing нужен. Плюс отдельная задача:
режим Publishing-only (только авторские права, без дистрибуции на DSP).

КОНТЕКСТ:
Broma16 разделяет:

Distribution (смежные права) — через создание релиза
Publishing (авторские права) — через создание произведения (composition)
Broma16 API для publishing:
POST /repertoire/composition — создать произведение
POST /repertoire/composition/{id}/contributors — добавить авторов
POST /repertoire/composition/{id}/step — завершить (step="completed")

ЧТО НУЖНО:

5A. При отправке релиза с авторами → controlled_by_submitter: true
(чтобы авторские права собирались)

5B. Publishing-only режим:
В разделе /publishing добавь возможность создать произведение БЕЗ релиза:
- Кнопка "Добавить произведение" (или подобное)
- Форма: название, авторы с долями (валидация = 100%), жанр, ISRC (если есть)
- При отправке в Broma16:
→ POST /repertoire/composition
→ POST /repertoire/composition/{id}/contributors
→ POST /repertoire/composition/{id}/step (step="completed")
→ НЕ создавать релиз, НЕ загружать аудио, НЕ выбирать витрины
- controlled_by_submitter: true
- Статус: "Published (Publishing only)"

ПРОВЕРКА: создай тестовое произведение через publishing-only режим,
убедись что оно уходит в Broma16 без создания релиза.
