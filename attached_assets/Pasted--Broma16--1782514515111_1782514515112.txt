ОТВЕТ НА ВОПРОС (а) — Витрины и типы релизов
Витрины (площадки) → ДА, переключи на словарь Broma16 (39 площадок).
Это явная польза — артист увидит все доступные площадки, включая таджикские (TCell и др.).
Переключи пикер в мастере создания релиза с локального dsp_catalog (30) на словарь Broma16 (39).

Типы релизов → НЕТ, оставь текущий enum (4 типа).
Не ломай бизнес-логику. Текущий маппинг (single=51, album=2) работает.
TikTokRelease и другие специфичные типы Broma16 нам пока не нужны.

ОТВЕТ НА ВОПРОС (б) — ACRCloud тест
ДА, помоги настроить и прогнать тестовый drop. Двухшаговый план:

ШАГ 1: Тест в local-fs режиме (без AWS)
Включи DDEX_ALLOW_LOCAL_FS=1
Создай тестовый релиз: UPC + 1 трек с реальным аудио (WAV) + обложка (JPG)
Используй любой короткий WAV файл (можно сгенерировать тестовый)
Это заполнит таблицу assets (сейчас 0)
Запусти drop → пакет должен записаться в локальную папку
Покажи мне структуру: XML + аудио + обложка
Покажи сгенерированный DDEX ERN 4.3 XML — я проверю что структура правильная
ШАГ 2: Реальный drop в S3 (после проверки Шага 1)
Я введу ACRCloud S3 ключи через Настройки → Интеграции (не через .env!)
access_key_id: (введу через UI)
secret_access_key: (введу через UI)
Отключи local-fs режим
Запусти drop снова → пакет должен улететь в бакет acrcloud-partners/TajikMusic/
Подтверди, что файл появился в S3
ДОПОЛНИТЕЛЬНО — создай мне тестовые данные
Поскольку assets = 0, мне нужен хотя бы один ПОЛНОЦЕННЫЙ релиз для тестов.
Создай тестовый релиз программно или помоги создать через UI:

Релиз:

title: "Test Release ACRCloud"
UPC: 1234567890123 (любой валидный)
тип: Сингл
жанр: любой из Broma16
дата релиза: 2026-07-01
P-Line / C-Line: заполнить
артист: существующий из сида
1 трек:

title: "Test Track"
ISRC: TJXXX2600001
аудио: нужен реальный WAV файл (сгенерируй тестовый или возьми любой)
-genre: из Broma16 словаря
обложка:

JPG, минимум 1400x1400px (сгенерируй тестовую)
Publishing (КРИТИЧНО для будущей отправки в Broma16):

1 автор: "Test Author", роль CA (composer+lyricist), доля 100%
Этот тестовый релиз закроет сразу несколько задач:

Заполнит assets (для ACRCloud drop)
Покажет что загрузка аудио/обложки работает на реальных файлах
Подойдёт для теста отправки в Broma16 позже
