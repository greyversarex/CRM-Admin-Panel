Теперь разберёмся с шагом 9 (distribution).

Endpoint из документации Broma16:

text

POST /repertoire/release/{releaseId}/distribution
Из руководства Broma16 (раздел "Рабочий процесс", шаг 10):

"Отправить витрины закреплённые за релизом
POST repertoire/release/{releaseId}/distribution
Параметр delivery_start_time — Дата отгрузки релиза на витрины — доступен аккаунту
по отдельной договоренности с площадкой. Также параметр distribution_outlets
предоставляет возможность указать отдельно витрины с персональной датой и временем."

ПОДХОД: попробуй варианты и проверяй ответ Broma16
Broma16 на ошибки возвращает 422 с описанием. Используй это как обратную связь.

ВАРИАНТ 1 (простой — список кодов витрин + дата):

JSON

{
  "sale_start_date": "2026-07-15",
  "distribution_outlets": ["spotify", "apple", "yandex", "vk"]
}
ВАРИАНТ 2 (если варианты 1 не примет — витрины как массив объектов):

JSON

{
  "sale_start_date": "2026-07-15",
  "distribution_outlets": [
    { "outlet": "spotify" },
    { "outlet": "apple" },
    { "outlet": "yandex" },
    { "outlet": "vk" }
  ]
}
ВАРИАНТ 3 (если distribution_outlets не работает — просто outlets):

JSON

{
  "sale_start_date": "2026-07-15",
  "outlets": ["spotify", "apple", "yandex", "vk"]
}
ЧТО ДЕЛАТЬ:
Пройдись по каждому варианту по очереди
Отправляй запрос и смотри ответ:
200/201 → успех, формат верный
422 → прочитай текст ошибки — он покажет что не так
Текст 422 ошибки ВАЖЕН — он часто содержит имена требуемых полей
Если все 3 варианта дали 422 — покажи мне ТОЧНЫЙ текст ошибки от каждого
ДОПОЛНИТЕЛЬНО — проверь через OpenAPI spec
Документация Broma16 — это Redoc (сгенерирована из OpenAPI).
Попробуй найти исходный OpenAPI JSON — там точная схема request body.
Возможные URL:

https://broma16.com/partner-api/partner-api.ru.json
https://broma16.com/partner-api/swagger.json
поиск по странице документации: Ctrl+F "distribution" — найди точный request body
ДОПОЛНИТЕЛЬНО — упрощённый запрос
Если все варианты со списком витрин не работают, попробуй МИНИМАЛЬНЫЙ запрос —
просто дата, без витрин:

JSON

{
  "sale_start_date": "2026-07-15"
}
Broma16 может принять это и назначить дефолтные витрины.

ЕСЛИ НИЧЕГО НЕ СРАБОТАЕТ:
Покажи мне все 422 ошибки (точный текст) — я пойму что не хватает.
В крайнем случае — обратимся к поддержке Broma16.
